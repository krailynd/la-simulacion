# 🧪 La Simulación — SahaHacking Virtual Lab

Web application of **SahaHacking**, the virtual-laboratory platform built for Universidad San Juan Bautista (UPSJB) courses: interactive simulators that let students practice course topics in the browser instead of only reading about them.

## What this is

- 🎛️ Part of the SahaHacking ecosystem (31+ simulators across university subjects).
- 🌐 TypeScript web app (`app/` router structure, shared UI components in `components.json` setup).
- 🎓 Built and maintained by students, for students — I led this project at UPSJB.
